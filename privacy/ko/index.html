2026-11-12 · 앱 / App: Zuna Facecap (Android, dev.zuna.facecap, 테스트판 / test build dev.zuna.facecap.dev)

요약: 카메라 영상은 폰 밖으로 나가지 않습니다. 계정·광고·분석 도구가 없고, 우리는 아무 데이터도 받지 않습니다.

  1. 카메라: 얼굴·몸·손 추적은 폰 안에서만 합니다. 영상과 사진은 저장하지도, 보내지도 않습니다.
  2. 보내는 것: 사용자가 고른 PC(같은 Wi-Fi)로 추적 결과 숫자(표정 값, 고개·몸 각도, 시간)만 보냅니다. 받는 곳은 사용자의 PC이고, 우리 서버로는 아무것도 보내지 않습니다.
  3. 폰에 저장하는 것: 설정, 보정 값(무표정·표정 범위, 몸 자세), 덱 허용 토큰. 앱 안에만 있고 앱을 지우면 같이 지워집니다. 사용자가 직접 '저장'을 누를 때만 녹화(표정 값 JSON), 개발자 기록, 배터리·발열 기록 파일을 폰의 Download/ZunaFacecap에 만듭니다.
  4. 덱: 덱 탭은 사용자의 PC가 내주는 페이지를 같은 Wi-Fi 안에서 엽니다.
  5. 업데이트 확인 (Play 스토어판에는 없음): 직접 내려받은 판은 하루 두 번까지 GitHub에 최신 버전을 묻습니다. 이때 GitHub는 일반적인 웹 요청처럼 IP 주소를 볼 수 있습니다. 기기·사용자 정보는 보내지 않습니다.
  6. 권한: 카메라(추적), 인터넷·Wi-Fi 상태·멀티캐스트·근처 기기(같은 Wi-Fi의 PC와 주고받기), 알림·포그라운드 서비스·절전 방지 ('화면 꺼져도 추적 유지'를 켰을 때만), 앱 설치(직접 내려받은 판의 업데이트만).
  7. 아이: 어린이를 대상으로 하지 않으며, 누구의 개인정보도 모으지 않습니다.
