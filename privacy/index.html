Privacy policy

2026-11-12 · 앱 / App: Zuna Facecap (Android, dev.zuna.facecap, 테스트판 / test build dev.zuna.facecap.dev)

Summary: camera video never leaves the phone. No accounts, ads or analytics, and we receive no data.

  1. Camera: face, body and hand tracking run on the phone only. Video and images are never stored or sent.
  2. What is sent: only tracking numbers (expression values, head and body angles, timestamps) to a PC the user chooses on the same Wi-Fi. The receiver is the user's own PC; nothing is sent to us.
  3. Stored on the phone: settings, calibration values (resting face, expression ranges, body posture) and the deck approval token, inside the app only; uninstalling removes them. Recording files (expression values as JSON), developer logs and battery/heat logs are written to Download/ZunaFacecap only when the user presses Save.
  4. Deck: the Deck tab opens a page served by the user's PC on the same Wi-Fi.
  5. Update check (not in the Play Store version): the directly downloaded version asks GitHub for the latest release up to twice a day. GitHub can see the IP address like any web request. No device or user information is sent.
  6. Permissions: camera (tracking); internet, Wi-Fi state, multicast and nearby devices (talking to the PC on the same Wi-Fi); notifications, foreground service and wake lock (only when "Keep tracking with the screen off" is on); installing packages (updates of the directly downloaded version only).
  7. Children: not directed at children; no personal data is collected from anyone.
